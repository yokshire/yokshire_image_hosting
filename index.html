Research Figure Hosting Assets

This repository serves manuscript and Notion figures as static assets. The canonical raster files live in /figures/, and page content should reference those hosted files directly so GitHub remains the source of truth for edits and history.

Primary Assets

Hosted figure files are published under /figures/.

Notion Wrappers

Legacy SVG wrappers remain available under /notion_github_hosted_figures/ for compatibility workflows.

Operating Rule

  • Edit the GitHub repository contents when figures change.
  • Keep Notion and manuscript links pointed at hosted GitHub assets.
  • Treat this site as delivery only, not as a separate content source.
